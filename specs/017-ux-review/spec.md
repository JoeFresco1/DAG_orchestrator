# UX review

Review the running product's primary user journeys with realistic content. Use the browser at desktop and mobile widths. Inspect navigation, hierarchy, typography, spacing, interaction feedback, empty and error states, and keyboard use. Capture actual screenshots of consequential findings. Compare the result with the product specification and the design reference produced earlier in the run.

Write a concise report with the journey and viewport tested, how to reproduce each finding, its effect on the user, and the expected behavior. Mark observations that could not be performed. Give the final QA worker enough detail to fix defects and repeat the affected journeys. Taste judgments need a visible example and an explanation of the user impact.
